##Course Objectives

This course incorporates the basic concepts of C# programming, problem solving
id programming logic, as well as the design techniques of an object-oriented,
event-driven language. • A high priority is given to writing applications that are easy for the user to
understand and to use. • The course is rich in concise, practical, and real-world example programs, so the student not only learns how to use the various controls, constructs, and features of
Visual C#. but also learns why and when to use them
